## 🛠️ How to Run Locally

You can run any of the prototypes directly:
- **Direct browser opening:** Simply double-click `app.html`, `design-system.html`, or `index.html` in your file explorer.
- **VS Code Live Server:** Right-click `app.html` and click **"Open with Live Server"**.
- **Python Local Server:** Run `python -m http.server 5173` in the project root and navigate to `http://localhost:5173/app.html`.
